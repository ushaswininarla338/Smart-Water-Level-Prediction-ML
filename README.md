
# Smart Water Level Prediction Using Machine Learning

## Project Description
This project predicts water levels using sensor data and Machine Learning algorithms.

## Dataset
- IR Sensor
- Ultrasonic Sensor
- Accelerometer
- Gyroscope
- Water Level

## Algorithms Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

## Tools
- Python
- Google Colab
- Scikit-learn
- Pandas
- Matplotlib

## Results
Random Forest achieved the best prediction accuracy among all the tested models.
